## 2025-02-20 - Dual-labeling and Explicit ARIA States for Floating Widgets
**Learning:** Icon-only floating action buttons (FABs), like a persistent ChatBot toggle or WhatsApp link, pose specific accessibility challenges. Relying solely on `aria-label` assists screen readers but leaves sighted keyboard/mouse users without clear tooltip context if they are unfamiliar with the icon. Furthermore, togglable widgets require explicit state management.
**Action:** Always implement dual-labeling for icon-only floating buttons: use `aria-label` for screen reader semantic meaning and `title` to provide a native visual tooltip on hover. Additionally, if the widget acts as a toggle (e.g., opening a chat window), ensure `aria-expanded={isOpen}` is explicitly declared on the trigger button to announce the state change dynamically. Lastly, combine these with explicit `focus-visible` styles to ensure keyboard navigation remains highly visible against potentially complex backgrounds.
