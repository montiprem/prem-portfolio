## 2024-05-24 - Floating Widget Keyboard Accessibility
**Learning:** Floating action buttons and chat widgets (often powered by Framer Motion) frequently lack default focus outlines, making them invisible to keyboard navigation users. Because these widgets are positioned absolutely or fixed and overlaid on the main content, providing explicit and appropriately colored `focus-visible` offset rings (e.g., matching the widget's primary color with an offset that contrasts against the background) is critical for WCAG compliance and standard keyboard UX flow. Furthermore, icon-only buttons require explicit `aria-label` and `title` tags so both screen readers and pointer-users can infer their function.
**Action:** When implementing new floating or sticky UI elements, explicitly test tab navigation and provide custom focus rings using `focus-visible:ring-2 focus-visible:outline-none focus-visible:ring-[color] focus-visible:ring-offset-2`. Always provide `aria-label` and `title` to interactive icons, and manage `aria-expanded` state on toggles that open floating windows.
