## 2025-02-14 - Dynamic ARIA and Focus-Visible in Floating Chat Widgets
**Learning:** For React toggle widgets like chat bubbles, screen readers need dynamic state beyond just `aria-expanded`. When the widget opens, the toggle button's `aria-label` should change (e.g. from "Open Chat" to "Close Chat") to accurately reflect its current action. Additionally, icon-only buttons nested inside floating, dark-themed widgets (like `#0b1220`) need explicit `focus-visible` offset styling (e.g. `focus-visible:ring-offset-[#0b1220]`) to ensure the focus ring contrast meets accessibility standards.
**Action:** When reviewing floating interactive widgets in React, always check for dynamic `aria-label` toggling alongside `aria-expanded`, and ensure focus ring offsets are styled specifically for the component's background color instead of relying on global defaults.
