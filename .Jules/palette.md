## 2026-09-08 - Dynamic ARIA Labels on Toggle Buttons\n**Learning:** When a single button toggles state (like a chat window opening/closing), a static `aria-label` (e.g., 'Open AI Chat') becomes inaccurate once the state changes. Screen readers need to know the *current* action the button will perform.\n**Action:** Use a dynamic `aria-label` (e.g., `aria-label={isOpen ? 'Close AI Chat' : 'Open AI Chat'}`) and pair it with `aria-expanded={isOpen}` to give assistive technology complete context about the button's dual purpose and current state.
