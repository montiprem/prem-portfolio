## 2023-10-27 - [Floating Interactive Widgets A11y]
**Learning:** Overlapping fixed/floating UI components (like a ChatBot and a WhatsApp button located in the same bottom corner) can cause pointer event interception issues during automated verification (and potentially for users with limited motor control). Furthermore, icon-only buttons in these widgets often lack ARIA labels, rendering them inaccessible to screen readers.
**Action:** When working with floating widgets, ensure all icon-only interactive elements (toggle buttons, send buttons, close buttons) have explicit `aria-label` and `title` attributes. If using automated testing (like Playwright), be prepared to use JavaScript `page.evaluate()` clicks to bypass layout-induced "subtree intercepts pointer events" errors.
